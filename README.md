# Takedown Desk

Free WordPress plugin by [Swift Web Dev](https://swiftwebdev.com/). Take It Down Act removal requests inside WordPress: a notice link, a request form, a 48-hour deadline clock, one-step removal of the item and its identical copies, and a dated record.

- WordPress.org slug: `takedown-desk`
- Requires WordPress 6.5+, PHP 7.4+
- License: GPLv2 or later

See [readme.txt](readme.txt) for the full description and the external services this plugin can use.

## Releasing

Bump `Version` in `takedown-desk.php`, `TKDESK_VERSION` and `Stable tag` in `readme.txt`, add a changelog entry, then push a tag with the same version number. The workflow publishes it to WordPress.org.
